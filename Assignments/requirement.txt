Implement a HomeAutomationEngine class that manages smart devices and supports automation rules with basic conflict handling.


Requirements:s
Device Management
add_device(device_id, name, type, room)
Devices store: current_state (dict), last_updated


Control Device
update_device(device_id, new_state) → Updates state and triggers rules
Rule System (Core Part)
add_rule(rule) where rule is:


Python
{
    "rule_id": "r1",
    "name": "Auto Lights",
    "priority": 7,                    # Higher number = higher priority
    "trigger_device": "motion1",
    "condition": "on",                # "on" or "off"
    "target_device": "light1",
    "action": "on"                    # "on", "off", or "set"
}


Key Logic:
When a device is updated, automatically check and execute matching rules.
If multiple rules affect the same target device, the rule with higher priority wins.
If same priority → skip the conflicting action and log a warning.

Required Methods:
add_device(...) 
update_device(device_id, new_state_dict)
add_rule(rule_dict)
get_all_devices()
get_device_history(device_id) → last 10 changes
Test Cases (Must Pass):
Python
engine = HomeAutomationEngine()

engine.add_device("motion1", "Living Motion", "sensor", "Living")
engine.add_device("light1", "Living Light", "light", "Living")
engine.add_device("ac1", "Living AC", "ac", "Living")

# Rule 1: Motion ON → Light ON (Priority 8)
engine.add_rule({
    "rule_id": "r1", "priority": 8,
    "trigger_device": "motion1", "condition": "on",
    "target_device": "  ", "action": "on"
})

# Rule 2: Motion ON → Light OFF (Priority 5) → Should be ignored
engine.add_rule({
    "rule_id": "r2", "priority": 5,
    "trigger_device": "motion1", "condition": "on",
    "target_device": "light1", "action": "off"
})

engine.update_device("motion1", {"status": "on"})
